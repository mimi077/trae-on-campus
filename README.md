# Trae on Campus · Campus Hub 校园一站式平台

> Trae on Campus 校园开发者活动参赛项目，成功入围。

## 项目简介

Campus Hub 是校园一站式平台，覆盖**闲置交易、失物招领、活动报名**三大业务闭环，并在后续迭代中补齐行政通知、课表导入与闲置发布 AI 辅助等能力。项目基于 Trae + T3 全栈框架开发，已公网部署。

## 我的角色：队长（5 人团队）

- 担任 5 人小队队长，团队由 3 名大一、1 名大三同学组成，全员无前后端开发基础；基于 Trae + T3 全栈框架，主导 Campus Hub 校园一站式平台从 0 到可演示版本开发，覆盖闲置交易、失物招领、活动报名三大业务闭环，项目成功入围。

## 技术栈

Next.js 15（App Router）· TypeScript · Tailwind CSS · tRPC 11 · Prisma 6 · SQLite

## 功能概览

| 业务域 | 核心能力 |
| --- | --- |
| 闲置交易 | 发布/编辑、流转标签、14 天到期提醒、收藏与意向、出价聊天、心愿求购 |
| 失物招领 | 寻物与招领发布、管理员审核、公开留言、状态流转 |
| 活动事务 | 活动广场与筛选、在线报名、名额管理、教师审核、报名名单、作品专区 |
| 平台底座 | 学号/工号统一登录、通知聚合、个人中心、审计日志 |
| 扩展能力 | 行政通知与定时发布、课表 CSV 导入、闲置发布 AI 润色与参考定价 |

## 目录结构

```
src/app          页面路由（活动、闲置、失物、通知、后台等）
src/components   业务组件与 UI 组件
src/server       tRPC 路由、鉴权、数据库、定时任务
src/lib          规则模块（报名、名额、提醒、富文本等）与常量
prisma           Schema 与种子数据
tests/rules      核心业务规则单元测试
docs             PRD 与安全自检报告
```

## 本地运行

```bash
npm install
npm run setup     # 初始化数据库并写入种子数据
npm run dev
```

默认访问 http://localhost:3000 ，健康检查 `/api/health`。
