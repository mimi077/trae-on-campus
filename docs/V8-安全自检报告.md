## 三、安全自检

| 检查项 | 结论 | 说明 |
| --- | --- | --- |
| 越权访问作品管理 | 已防护 | `staffProcedure` + 活动归属校验；非发布者 / 非管理员返回 FORBIDDEN |
| 越权审核他人活动 | 已防护 | 沿用 `staffProcedure`，审核动作写入 `AdminLog` |
| 存储型 XSS（富文本） | 已防护 | 服务端 `sanitizeRichText` 白名单：仅保留基础排版，移除 script/iframe/svg/style、`on*` 事件、`javascript:` / `data:` 协议 |
| 外链协议注入 | 已防护 | 作品链接、封面、多媒体、活动外链统一要求 `http(s)` |
| 富文本二次渲染 | 已防护 | 详情页渲染前再次净化，双保险 |
| 提醒重复推送 | 已防护 | `(activityId,userId,stage)` 唯一索引 + 事务 + P2002 兜底 |
| 邮件退信 / 未配置 SMTP | 可审计 | 邮件先入 `EmailOutbox`，状态 `PENDING / SENT / SIMULATED / FAILED` |
| 提交资格绕过 | 已防护 | 服务端校验报名 `APPROVED`、截止时间、作品是否已通过审核 |
| 截止后提交 | 已拒绝 | `evaluateSubmission` 服务端判定，前端倒计时仅作展示 |
| 弹窗次数限制 | 已实现 | localStorage 按本地日期计数，单日最多 3 次；服务端不做持久化 |
| 无限名额绕过 | 已防护 | 名额判断统一走 `isUnlimited`，历史 Int 约束保留 |
| 审核驳回无原因 | 已拒绝 | 活动与作品驳回均要求不少于 5 字原因 |
| 未登录写操作 | 已拒绝 | 统一 `UNAUTHORIZED`；写操作限流沿用 |
| 演示数据泄露真实隐私 | 已控制 | 仅演示账号与虚构作品；名单姓名脱敏 |
| 定时任务多实例冲突 | 部分缓解 | 单实例进程内调度 + 数据库唯一索引；多实例建议仅主实例启用或改外部 Cron |
| SQLite 持久性 | 已知限制 | `/tmp` 数据库随实例重启重置，仅用于演示 |

## 四、已知限制与上线建议

1. **邮件为模拟发送**：未配置 SMTP 时邮件仅落库并标记 `SIMULATED`。配置 `SMTP_*` 后可真实投递；`APP_BASE_URL` 用于生成邮件内绝对提交链接。
2. **SQLite 演示库**：多实例不共享 `/tmp`。正式环境建议 Postgres / Turso。
3. **多实例定时任务**：当前为进程内每分钟扫描。多实例部署时请仅主实例设置 `REMINDER_INTERVAL_MS` 调度，其余实例设置 `DISABLE_REMINDER_SCHEDULER=1`。
4. **Safari / Firefox**：受当前环境限制未做真机回归，建议上线前补测。
5. **作品媒体存储**：当前使用外链 URL，未接入对象存储；正式环境建议接入 OSS / S3 并做类型与大小校验。
